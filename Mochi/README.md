# 团团 · 桌面小狗

根据你提供的视频制作的黑色垂耳小奶狗，采用软萌毛绒外观。原生 macOS 客户端，无账号、无网络请求、无额外运行时。

## 安装与使用

适用于 Apple Silicon Mac（M1/M2/M3/M4 等），macOS 13 或更新版本。当前交付包为 arm64。

双击 `安装团团.command`，会安装到个人的 `~/Applications/团团桌面宠物.app`，不需要管理员密码。也可以直接打开 `dist/团团桌面宠物.app`。

- 点击小狗：摸摸它，会冒出爱心。双击：开心地跳起来。
- 拖动小狗：抱起来、挪到你喜欢的位置；可以放到不同显示器。
- 鼠标从附近经过：它偶尔会好奇地跟着走。右键可直接点播动作。
- 顶部菜单栏的爪印：打开小窝、暂停、暂时隐藏、把小狗叫回来或退出。
- 关闭“小窝”窗口后，小狗仍会留在桌面。
- 名字可直接修改，大小、跑步速度和生活习惯都会保存。

睡觉、跳跃、转圈、奔跑、打滚、翻身、握爪、摸摸、吃零食、拉粑粑和撒尿均可手动触发。平时还有呼吸、眨眼、摇尾巴和歪头。上厕所痕迹随动作结束自动消失。“偶尔自己上厕所”控制是否自动触发，手动动作仍可使用。

“只在屏幕底部活动”可以减少对工作区的打扰；透明区域允许鼠标穿透，不拦截其他窗口。暂时隐藏会停止动画和移动。系统睡眠或锁定后会暂停，恢复时重新检查屏幕位置。

## 开机启动

打开小窝 → 更多设置 → **登录 Mac 时来找我**。使用 Apple 的 [SMAppService.mainAppService](https://developer.apple.com/documentation/servicemanagement/smappservice/mainapp?language=objc) 注册登录项。首次使用保持关闭，由你决定是否开启。

如果 macOS 要求批准，点“打开系统登录项”，在系统设置中允许团团。开关会展示系统真实状态，不会只保存一个看似开启的偏好。

这里的“开机启动”指登录你的 Mac 用户账户后自动运行。没有执行真实的注销或重新启动测试。

## 构建

需要 macOS 13+、Apple Command Line Tools（clang）以及 Python 3（仅用于图标打包的后备路径）。不需要 Xcode 工程、Swift 包管理器、npm 或联网下载依赖。

```bash
bash build.sh
"dist/团团桌面宠物.app/Contents/MacOS/Mochi" --self-test
"dist/团团桌面宠物.app/Contents/MacOS/Mochi" --render-preview "$PWD/dist/动作预览.png"
mkdir -p build/qa
"dist/团团桌面宠物.app/Contents/MacOS/Mochi" --smoke-test "$PWD/build/qa"
```

图形检查需要在已登录的 macOS 图形会话中运行。`--smoke-test` 调用真实动作处理方法、检查透明命中区域并渲染真实 AppKit 界面，不会合成鼠标事件或读取其他应用。

`--startup-status` 只读查看系统登录项状态。`--test-startup` 是维护用诊断，会临时注册登录项、读取状态并还原关闭；如果原本已配置，则保持原状。

## 本机验证记录

在 macOS 15.1 / Apple Silicon 上完成：

- 编译通过 `-Wall -Wextra -Werror`，应用签名验证通过。
- 2761 项状态、计时、暂停、拖动、屏幕边界与素材断言通过。
- 12 个真实动作按钮处理方法、透明像素命中、手动睡眠/叫醒、暂停/继续检查通过。
- 渲染并目视检查了小窝、更多设置和动作预览，修复了预览卡片的绘制溢出。
- 已安装到个人 Applications 文件夹，并确认主进程持续运行。
- 在运行中的应用内执行 `--verify-login-item`：系统注册成功，状态为 `enabled`；随后成功注销，还原为关闭。

电脑控制工具没有取得本机权限，因此未完成真实鼠标点击/拖动的自动端到端测试；应用本身无需该权限。没有实际注销或重启 Mac，也没有实体多显示器切换测试（已检查含负坐标的多屏几何边界）。

## 文件与实现

- `Sources/App.m`：透明桌面窗口、菜单栏、小窝界面、互动、偏好、登录项。
- `Sources/PetModel.*`：动作状态、计时、移动边界。
- `Sources/PetRenderer.*`：透明姿势图、连续位移、摇尾、眨眼、呼吸和粒子效果。
- `Assets/puppy-atlas.png`：内置 imagegen 生成的原始透明素材；`ASSETS.md` 记录提示词。
- `Tools/prepare-assets.m`：按透明连通区域提取 12 个姿势，避免等分网格裁到耳朵。
- `dist/`：可运行 `.app`、安装压缩包和预览。

动画是透明姿势图配合连续变换、两帧跑步循环和特效，并非完整的实时 3D 骨骼模型。

本地构建使用 ad-hoc 签名，未进行 Apple Developer ID 公证。当前包面向这台 Mac 的本地使用；公开分发到其他 Mac 前，应使用开发者证书签名、公证，并按需构建 Universal Binary。不要关闭系统安全防护。

程序不读取键盘、屏幕截图、文档或浏览器内容；只读取鼠标位置用于互动。无需辅助功能或屏幕录制权限，测试工具的电脑控制权限与宠物程序无关。

## 卸载

先在“更多设置”关闭登录自启，再从菜单栏退出团团，把应用移到废纸篓即可。偏好保存在 `com.mochipet.desktop` 的 macOS 用户偏好中。
